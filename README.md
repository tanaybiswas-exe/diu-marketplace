## 🌟 About The Project

**DIU Marketplace** হল ড্যাফোডিল ইন্টারন্যাশনাল ইউনিভার্সিটির (DIU) শিক্ষার্থীদের জন্য তৈরি একটি সেন্ট্রালাইজড এবং নিরাপদ মার্কেটপ্লেস প্ল্যাটফর্ম। এর মাধ্যমে শিক্ষার্থীরা ক্যাম্পাসের ভেতরে বা আশেপাশের এলাকা থেকে খুব সহজেই নিজেদের প্রয়োজনীয় পণ্য (যেমন: হস্তশিল্প, পোশাক, এক্সেসরিজ ইত্যাদি) কেনাবেচা ও আদান-প্রদান করতে পারে।

---

## ✨ Key Features

- **🛍️ Live Campus Market Feed:** রিয়েল-টাইমে ক্যাম্পাসের পণ্যগুলোর তালিকা এবং স্ট্যাটাস দেখা যায়।
- **📍 Location Tagging:** পণ্যের লোকেশন নির্দিষ্ট করা থাকে (যেমন: Permanent Campus Ashulia, DIU Smart City Gate ইত্যাদি), যাতে সহজে পিকআপ বা ডেলিভারি করা যায়।
- **❤️ Wishlist System:** পছন্দের পণ্যগুলো উইশলিস্টে সেভ করে রাখার সুবিধা।
- **🔔 Notification Center:** ব্যবহারকারীদের জন্য ইনস্ট্যান্ট নোটিফিকেশন সিস্টেম।
- **🔐 Secure Campus Ecosystem:** শুধুমাত্র ডিআইইউ কমিউনিটির জন্য একটি বিশ্বস্ত প্ল্যাটফর্ম।
- **📱 Fully Responsive UI:** যেকোনো ডিভাইস বা স্ক্রিন سাইজে সুন্দরভাবে কাজ করার উপযোগী ডিজাইন।
