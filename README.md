## 📖 About The Project

**DIU Marketplace** হল ড্যাফোডিল ইন্টারন্যাশনাল ইউনিভার্সিটির (DIU) শিক্ষার্থীদের জন্য বিশেষভাবে তৈরি একটি সেন্ট্রালাইজড ও নিরাপদ ইকোসিস্টেম। ক্যাম্পাসের ভেতরে বা আশেপাশের এলাকা থেকে ছাত্র-ছাত্রীরা খুব সহজেই তাদের প্রয়োজনীয় পণ্য যেমন—হস্তশিল্প, জামাকাপড়, এক্সেসরিজ এবং স্টাডি মেটেরিয়ালস কেনাবেচা বা এক্সচেঞ্জ করতে পারেন।

## ✨ Key Features & Highlights

| Feature | Description |
| :--- | :--- |
| **🛍️ Live Campus Feed** | রিয়েল-টাইমে ক্যাম্পাসের পণ্যগুলোর তালিকা এবং বর্তমান স্টক স্ট্যাটাস দেখুন। |
| **📍 Smart Location Tagging** | নির্দিষ্ট লোকেশন ট্যাগ (যেমন: *Permanent Campus Ashulia*, *DIU Smart City Gate*) সহ সহজে পিকআপ পয়েন্ট চুজ করুন। |
| **❤️ Personal Wishlist** | পছন্দের আইটেমগুলো সেভ করে রাখুন যাতে পরবর্তীতে দ্রুত খুঁজে পাওয়া যায়। |
| **🔔 Instant Notifications** | আপডেট ও অর্ডার সম্পর্কিত রিয়েল-টাইম নোটিফিকেশন সিস্টেম। |
| **🔒 Campus Compliance** | শুধুমাত্র ডিআইইউ কমিউনিটির জন্য একটি নিরাপদ ও বিশ্বস্ত ট্রেডিং প্ল্যাটফর্ম। |
| **📱 Fully Responsive UI** | মোবাইল, ট্যাবলেট বা ডেস্কটপ—সব ডিভাইসেই দারুণ ইউজার এক্সপেরিয়েন্স। |
